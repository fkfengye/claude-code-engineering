解释以下代码或概念：$ARGUMENTS

## 解释风格

使用"教朋友"的 approach：

1. **从头开始**：一句话总结代码做什么
2. **逐步拆分**：逐步讲解逻辑
3. **使用类比**：适时用日常概念进行对比
4. **突出重点**：指出重要的部分

## 输出格式

```markdown
## 它做什么
[一句话总结]

## 它如何工作

### 逐步讲解
1. 首先，[第一步发生了什么]
2. 然后，[接下来发生了什么]
...

### 关键概念
- **[概念]**：[解释]

## 示例
[如果有帮助，给出简单示例]

## 记住
[需要记住的一件事]
```

## 指南

- 假设读者正在学习
- 避免术语，或在使用时给出定义
- 代码示例有助于阐明时使用
- 保持简洁但完整
- 如果是解释文件，专注于最重要的部分
