以友好的格式显示当前 git 状态及有用的上下文信息。

## 步骤

1. 执行 `git status`
2. 以友好格式总结状态

## 输出格式

```
## Git 状态

分支：[分支名称]
状态：[clean / has changes / has conflicts]

### 已暂存的变更（可以提交）
- [文件列表]

### 未暂存的变更（未暂存）
- [文件列表]

### 未跟踪的文件
- [文件列表]

### 建议的后续步骤
- [接下来可能想做的事情]
```

如果仓库是干净的，直接显示：
```
✓ 工作树在分支 [name] 上是干净的
```
