# 盈利能力分析参考

## 利润率指标

### 毛利率
```
毛利率 = (收入 - 营业成本) / 收入 × 100%
```

**行业基准：**
| 行业 | 典型区间 |
|----------|--------------|
| 软件/SaaS | 70-85% |
| 零售 | 20-50% |
| 制造业 | 25-35% |
| 服务业 | 50-70% |

### 营业利润率
```
营业利润率 = 营业收入 / 收入 × 100%

营业收入 = 收入 - COGS - 运营费用
```

### 净利率
```
净利率 = 净利润 / 收入 × 100%

净利润 = 收入 - 所有费用 - 税费
```

### EBITDA 利润率
```
EBITDA 利润率 = EBITDA / 收入 × 100%

EBITDA = 净利润 + 利息 + 税费 + 折旧 + 摊销
```

## 回报率指标

### 投资回报率 (ROI)
```
ROI = (投资收益 - 投资成本) / 投资成本 × 100%
```

### 资产回报率 (ROA)
```
ROA = 净利润 / 总资产 × 100%
```

**基准：**
- > 10%：优秀
- 5-10%：良好
- < 5%：低于平均

### 股东权益回报率 (ROE)
```
ROE = 净利润 / 股东权益 × 100%
```

**基准：**
- > 15%：优秀
- 10-15%：良好
- < 10%：低于平均

### 杜邦分析（ROE 分解）
```
ROE = 净利率 × 资产周转率 × 权益乘数

其中：
- 净利率 = 净利润 / 收入
- 资产周转率 = 收入 / 总资产
- 权益乘数 = 总资产 / 股东权益
```

## 盈利能力警示信号

1. **收入增长但毛利率下降**（定价压力）
2. **营业利润率 < 0**（运营不盈利）
3. **ROE 远高于 ROA**（高杠杆风险）
4. **净利率连续 3 年以上低于行业平均**
5. **EBITDA 为正但净利润为负**（高利息/折旧负担）
