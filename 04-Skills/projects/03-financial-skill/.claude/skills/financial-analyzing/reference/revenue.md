# 收入分析参考

## 关键指标

### 收入增长率
```
收入增长率 = (本期收入 - 上期收入) / 上期收入 × 100%
```

**解读：**
- > 20%：高增长
- 10-20%：中速增长
- < 10%：低速增长
- < 0%：下降

### 同比增长率 (YoY)
```
YoY 增长 = (今年收入 - 去年收入) / 去年收入 × 100%
```

### 环比增长率 (QoQ)
```
QoQ 增长 = (本季度 - 上季度) / 上季度 × 100%
```

## 收入结构分析

### 按产品/服务分类的收入
```
产品收入占比 = 产品收入 / 总收入 × 100%
```

### 按地区分类的收入
```
地区收入占比 = 地区收入 / 总收入 × 100%
```

## 平均收入指标

### 每用户平均收入 (ARPU)
```
ARPU = 总收入 / 用户数
```

### 每账户平均收入 (ARPA)
```
ARPA = 总收入 / 账户数
```

## 需要关注的警示信号

1. **收入集中度** - 单个客户占比超过 30%
2. **增长率下降** - 连续 3 个以上季度下降
3. **确认收入与开票收入差异大**
4. **异常季节性模式**
