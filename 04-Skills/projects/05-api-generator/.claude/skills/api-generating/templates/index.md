# API 索引模板

为 API 概述页面使用此模板：

```markdown
# {API_NAME} API 参考

{简要描述 API 及其用途。}

## 基础 URL

```
{BASE_URL}
```

## 认证

{认证方法描述}

## 端点概览

| 方法 | 路径 | 描述 |
|------|------|------|
| {METHOD} | {PATH} | {简要描述} |

## 端点

### {分类_1}

- [{METHOD} {PATH}](#{anchor}) - {简要描述}

### {分类_2}

- [{METHOD} {PATH}](#{anchor}) - {简要描述}

## 常见响应码

| 码 | 描述 |
|------|------|
| 200 | 成功 |
| 201 | 已创建 |
| 400 | 错误请求 |
| 401 | 未授权 |
| 403 | 禁止 |
| 404 | 未找到 |
| 500 | 服务器内部错误 |

## 速率限制

{如果适用，速率限制信息}

## 版本控制

{如果适用，API 版本控制信息}
```
